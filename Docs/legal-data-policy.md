# Legal & data policy

AutoDJ learns setcraft from **lawful, attributable** sources and **user-owned** audio. It is not a pirate training corpus.

## Allowed

- User library analysis on-device / local cache.
- User-exported Rekordbox `DJ_PLAYLISTS` XML (paths + prep metadata only).
- Royalty-free and explicitly licensed reference packs.
- Public tracklists/charts ingested into **aggregate statistics** with citations.
- Synthetic transitions generated by the rule engine.
- Small human-labeled gold sets the project owns or has rights to.

## Forbidden in git / CI

- Commercial DJ set audio scraped from YouTube, SoundCloud, Mixcloud, etc.
- Wholesale HTML dumps of paywalled tracklist pages.
- Commercial Rekordbox collection / library XML dumps (commit only synthetic fixtures under `testdata/rekordbox/`).
- API keys, Bearer tokens, `.env` files.
- Unlicensed stem packs.

## Tracklist ingest rule

Parsers may fetch public pages when ToS allows. **Current CI path is offline-only:** local JSON fixtures, user-supplied CSV chart exports, and curated attributable setcraft rows under `python/autodj_train/datasets/fixtures/`. Committed datasets store only:

- Genre, BPM band histograms, key-route frequencies, transition-density estimates, BPM-center medians
- Source URL + retrieval date citations
- Derived `policy_hints` JSON (`bpm_center`, `default_crossfade_secs`) — no page HTML

**Gated (do not automate in-repo):** live 1001Tracklists scraping (anti-bot / no official public API), paid Beatport chart APIs, Mixonset undocumented endpoints. If a source forbids automation, skip it and note the gate in `Docs/competitive-automix-sweep.md`.
